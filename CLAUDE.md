# Gamerflix pack

The Gamerflix modpack (Minecraft 1.21.1, NeoForge) as a packwiz pack, served by GitHub Pages. Public repo.

- Read `README.md` first.
- Run `packwiz refresh` before every commit.
- Anything in the repo that isn't part of the pack must be listed in `.packwizignore`, or every player downloads it.

## Writing and commits

- Never use em dashes. Keep text short and to the point. No time estimates.
- No `Co-Authored-By` trailer or other Claude attribution on commits or PRs.
